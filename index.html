Complexity Analysis

Edmonds-Karp is Ford-Fulkerson where every augmenting path is found with breadth-first search, so the shortest path (fewest edges) is always used.

Time: O(V · E²). One BFS costs O(E). Each augmentation saturates at least one edge, and an edge can be the bottleneck at most V/2 times, so there are at most O(V · E) augmentations.

Space: O(V + E) with adjacency lists, plus the BFS queue and the parent of each node. This simulator follows the lesson and stores the residual graph as a V × V capacity matrix, so it uses O(V²) memory and each BFS scans O(V²) cells. That is simple and fast enough for the test networks.

The bound depends only on the size of the graph, never on the capacity values, which is why BFS is preferred over DFS.

About Us

System Description

MAXFLOW NETWORK SIMULATOR is a graphical application that calculates and demonstrates the maximum flow in a directed network. The maximum flow problem asks for the greatest amount of flow that can move from a source to a sink, where every connection has a capacity that limits how much it can carry.

Users can add nodes, create connections, assign capacity values, and choose the source and destination. The system draws the network, shows the augmenting paths and flow updates while the algorithm runs, and presents the maximum flow together with the flow assigned to each edge.
